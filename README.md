## âš¡ Quick Start Guide

### 1. Clone Repository
```bash
git clone https://github.com/sharatkumar-dev/SkillNexis-MERN-Stack-Internship.git
cd SkillNexis-MERN-Stack-Internship
```

### 2. Running Week 3 â€” Assignment 1: Full Stack To-Do Application

#### Start the Backend API:
```bash
cd "Week 3/01-todo-fullstack/backend"
npm install
cp .env.example .env
npm run dev
# Backend API runs on http://localhost:5000
```

#### Start the Frontend React + Vite SPA:
```bash
# In a new terminal tab:
cd "Week 3/01-todo-fullstack/frontend"
npm install
cp .env.example .env
npm run dev
# Frontend application runs on http://localhost:5173
```

### 3. Running Week 3 🏆 Mini Project: TaskFlow Task Manager

#### Start the Backend API:
```bash
cd "Week 3/03-task-manager-app/backend"
npm install
cp .env.example .env
npm run dev
# API runs on http://localhost:5002
```

#### Start the Frontend:
```bash
cd "Week 3/03-task-manager-app/frontend"

# App runs on http://localhost:5175 — click "Demo Login" for instant access
```
