# Assignment 1: Personal Portfolio Website

A responsive, modern personal portfolio website built with pure semantic **HTML5** and **CSS3** (incorporating Flexbox, CSS Grid, custom properties, and responsive media queries).

---

## ?? Features

- **Semantic HTML5 Architecture**: Implemented with `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` tags for search engine optimization (SEO) and accessibility.
- **Modern CSS3 Design System**:
  - CSS Custom Properties (CSS variables) for consistent theming and colors.
  - Glassmorphism & subtle background gradient lighting effects.
  - Interactive hover animations and card elevations.
- **Dedicated Sections**:
  1. **Hero & About**: Professional bio, skill tags, live status indicator, and social profile links.
  2. **Tech Stack & Skills**: Categorized skills (Frontend, Backend, Tools) with modern badges.
  3. **Education & Milestones**: Chronological timeline format displaying academic history and internship training.
  4. **Featured Projects**: Responsive CSS Grid displaying project cards with category badges, description, tech stack tags, and demo links.
  5. **Contact**: Interactive styled form with field focus rings and direct contact details.
- **100% Responsive Design**: Mobile-friendly navigation with pure CSS slide-out drawer, fluid typography, and dynamic grid restructuring for mobile, tablet, and desktop viewports.

---

## ?? How to Run

1. Open `01-portfolio/index.html` directly in any modern web browser (Chrome, Edge, Firefox).
2. Alternatively, serve via VS Code Live Server or python HTTP server:
   ```bash
   # From the 01-portfolio directory
   npx serve .
   ```
