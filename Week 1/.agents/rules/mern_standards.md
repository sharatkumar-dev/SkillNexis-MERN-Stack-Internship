# MERN Stack Internship Code Guidelines & Standards

## Code Quality & Architecture
1. **Semantic HTML5**: Always use proper landmark tags (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>).
2. **Modern CSS**:
   - Use CSS custom properties (variables) for consistent theming (colors, spacing, typography, radii).
   - Use Flexbox for 1D layouts and Grid for 2D card/gallery layouts.
   - Design mobile-first with clear responsive breakpoints (768px, 1024px, 1280px).
3. **React Best Practices**:
   - Write clean functional components with standard React Hooks (useState, useEffect, useMemo, useCallback).
   - Maintain clear separation between container/logic state and presentational components.
   - Use descriptive prop types, default props, and meaningful variable names.
   - Keep state minimal and derive values whenever possible.
4. **Documentation**:
   - Provide clean README.md files for every subproject with setup instructions, features, and key takeaways.
